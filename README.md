## 🧑🏻‍💻 About Me

- 🧮 **수학 / 과학 / 공학**을 사랑하며, 수학적 개념을 프로그래밍으로 풀어내는 것에 흥미를 느낍니다.
- 🔐 **알고리즘의 이론적 검증 및 응용**: 
  - 폴라드 로(Pollard's rho) 알고리즘의 시간 복잡도 분석
  - 고속 푸리에 변환(FFT) 알고리즘의 수학적 기반
  - 큰 정수(Big Integer) 구현에 필요한 수학적 정리 증명 및 구현
  - 다항식환(Polynomial Rings) 등의 수학적 개념을 활용한 양자 후 암호 알고리즘(NTRU) 구현
- 💡 고전 시퀀트 계산법(System LK) 기반의 대화형 증명 보조기(Proof Assistant) **Turnstile**을 개발했습니다.
- 🤖 **머신러닝 & 비전**: 이미지 분류에 뛰어난 성능을 보이는 **CNN** 및 **ResNet** 등의 딥러닝 아키텍처에 관심이 많습니다.
- 🖥️ **인프라 및 서버 운영**: Intel 기반 하드웨어에 Ubuntu OS 서버를 직접 구축 및 관리하고 있으며, SSH Key 기반의 안전한 로그인 환경 구성과 SSL 인증서를 활용한 HTTPS 프로토콜 기반 웹 서버를 구축한 경험이 있습니다.
